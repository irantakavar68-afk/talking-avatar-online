# آواتار سخنگوی آنلاین (فارسی)

وب‌اپلیکیشن آنلاین: متن + عکس چهره + فایل صوتی → ویدیوی لیپ‌سینک، بدون GPU و بدون کلاک/conda، با اجرای رایگان روی **Vercel**.

## معماری
- **فرانت‌اند**: `public/index.html` — آپلود مستقیم و بدون امضا (unsigned) عکس و صوت به Cloudinary.
- **سرورلس**: `api/talk.js` (ایجاد Talk در D-ID) و `api/status.js` (بررسی وضعیت و دریافت لینک ویدیو) و `api/config.js` (تنظیمات عمومی Cloudinary).
- **ذخیره فایل‌ها**: Cloudinary.
- **موتور لیپ‌سینک**: D-ID Talks API (حرکت لب از روی «صوت» ساخته می‌شود؛ متن فقط رونوشت/transcript است).

## مراحل اجرا
1. حساب D-ID بسازید و کلید API را بردارید (dash.d-id.com).
2. حساب Cloudinary بسازید و در Settings → Upload یک **Upload preset** با حالت **Unsigned** بسازید.
3. در Vercel پروژه را از این پوشه دیپلوی کنید و در Environment Variables این سه مقدار را تنظیم کنید:
   `D_ID_API_KEY`، `CLOUDINARY_CLOUD_NAME`، `CLOUDINARY_UPLOAD_PRESET`
4. سایت را باز کنید: متن + عکس (JPG/PNG ≤10MB) + صوت (MP3/WAV/M4A/FLAC/MP4 ≤50MB) → «ساخت ویدیو».
5. حدود ۳۰–۹۰ ثانیه صبر کنید تا لینک MP4 آماده شود؛ سپس پخش/دانلود کنید.

## نکته درباره «صوت خود شخصیت»
در این نسخه حرکت لب از روی فایل صوتی آپلودی ساخته می‌شود. اگر صوت آماده ندارید و می‌خواهید از روی متن گفتار ساخته شود، یک سرویس TTS/کلون صدا (مثل ElevenLabs یا Azure TTS) به زنجیره اضافه کنید: متن → صوت → همان مسیر فعلی.
